# 🐍 Pradeepp Snake Game

A classic Snake Game built using **Python** and **Pygame**.

## ✨ Features

- 🎮 Start Menu
- 🐍 Snake Growth
- 🍎 Random Food
- 🔊 Eat Sound Effect
- 💀 Game Over Sound
- 🎵 Background Music
- 🏆 High Score Saving
- ⚡ Dynamic Speed
- 🔁 Restart Option
- 🚧 Wall Collision
- 🐍 Self Collision

## 🎮 Controls

| Key | Action |
|------|--------|
| ↑ ↓ ← → | Move Snake |
| SPACE | Start Game |
| R | Restart |
| X | Close Window |

## 📦 Requirements

- Python 3
- Pygame

Install Pygame:

```bash
pip install pygame
```

## ▶️ Run

```bash
python snakegame.py
```
