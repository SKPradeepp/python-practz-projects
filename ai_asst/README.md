# 🤖 AI Assistant

A Python-based AI Assistant project developed as part of my Python learning journey.

## Features

* Chat-based AI interface
* Voice input and output
* GUI versions using Python
* Conversation history
* Memory and notes support

## Technologies Used

* Python
* Tkinter
* Speech Recognition
* Text-to-Speech
* Ollama (Local LLM)

## Files

* `pradeepp_ai_gui.py` – Main AI Assistant
* `gui_chatbox.py` – Chat interface
* `gui_voice_asst.py` – Voice Assistant
* `voice_asst.py` – Voice processing
* `memory.txt` – Assistant memory
* `notes.txt` – Notes storage
