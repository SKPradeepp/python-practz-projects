🐍 Pradeepp Snake Game

A classic Snake Game built using Python and Pygame.

Features
--------
✅ Start Menu
✅ Background Music
✅ Sound Effects
✅ High Score Saving
✅ Restart
✅ Dynamic Speed
✅ Better Graphics
✅ Wall Collision
✅ Self Collision

Controls
---------
↑ ↓ ← →  Move
SPACE    Start Game
R        Restart
X        Close Window

Requirements
------------
Python 3
Pygame

How to Run
----------
pip install pygame
python snakegame.py
